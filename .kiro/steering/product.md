# Product Overview

Net Worth Tracker is a personal finance PWA (Progressive Web App) for tracking assets and liabilities, with all values normalized to New Taiwan Dollars (TWD).

## Core Features
- Asset management: Taiwan stocks (TWSE/OTC), cryptocurrencies, cash, and other asset types
- Liability management: credit loans, home loans, pledge loans, revolving mortgages
- Real-time price fetching from TWSE and CoinGecko APIs
- USD/TWD currency conversion with configurable exchange rate (default 31.5)
- Net worth dashboard with pie chart (asset allocation) and trend line chart
- Daily net worth snapshots with automatic creation and 365-day retention
- Loan amortization calculator (equal payment and equal principal methods)
- Google Sheets integration for data sync
- Offline-capable with service worker caching
- Installable as a mobile/desktop PWA
- Data export/import via JSON

## Target Users
- Taiwanese individual investors managing a mixed portfolio of local stocks, crypto, and cash

## Language
- The UI is entirely in Traditional Chinese (zh-TW). All user-facing strings, labels, error messages, and code comments are written in Chinese.
